# 🧮 Python CLI Calculator

A simple yet structured **Python-based Command Line Calculator**, built as part of the *Build Your Own Project* evaluation.  
This project demonstrates clear functional modules, proper input/output flow, error handling, and modular programming concepts.

---

## 📌 Project Overview

This project is a menu-driven calculator application that performs basic arithmetic operations.  
It is designed to show understanding of Python fundamentals, modular coding, and real-world problem solving while meeting the academic requirements.

The calculator provides a clean user workflow, validates user input, and ensures safe execution of all operations.

---

## 🚀 Features (Functional Requirements)

This project contains **three major functional modules** as required in the guidelines :contentReference[oaicite:1]{index=1}:

1. **Input Module**  
   - Takes user choice and numeric inputs  
   - Handles invalid or non-numeric input

2. **Processing Module**  
   - Performs arithmetic operations  
   - Separate functions for each operation  
   - Division handles zero-division safely

3. **Output/Result Module**  
   - Displays results  
   - Shows error messages and re-prompts  
   - Provides menu-driven flow

Additional Features:
- Repeat operations without restarting the program  
- Clean exit option  
- Easily extendable structure

---

## 🛡 Non-Functional Requirements

As per the project guidelines (minimum 4 NFRs) :contentReference[oaicite:2]{index=2}

- **Usability:** Simple menu-based user interaction  
- **Reliability:** Exception handling prevents crashes  
- **Maintainability:** Modular functions, readable code  
- **Performance:** Runs instantly, minimal resources  
- **Error Handling:** Safe input validation + zero-division handling  
- **Scalability:** New operations can be added easily
